# Artwork

Logos of OpenReloading and its projects, monochrome, built on one open cog.

<p><img src="openreloading/openreloading-light.svg" height="56" alt="OpenReloading">&emsp;<img src="autolever/autolever-light.svg" height="56" alt="AutoLever">&emsp;<img src="ballistics/ballistics-light.svg" height="56" alt="Ballistics"></p>

Each folder has `<name>-icon.svg` (mark only, `currentColor`), `<name>-light.svg` and `<name>-dark.svg` (with wordmark), `<name>-icon-1024.png` (avatar) and `<name>-social-1280x640.png` (GitHub social preview).

`python3 generate.py` rebuilds everything (needs fontTools, the Fira Sans font, rsvg-convert and ImageMagick 7). Construction and rules: `CLAUDE.md`.

Built by reloaders for reloaders, with AI as a tool.
